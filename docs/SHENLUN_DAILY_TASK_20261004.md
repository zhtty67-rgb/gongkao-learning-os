# 申论每日任务

2026-10-04：学习概览和申论工作台新增每日1道申论任务，任务入口为 /shenlun?daily=1。工作台默认按每日模式进入：优先续写未完成会话，否则查看今天已完成的作答，或选择未练/最久未完成材料；过去已完成会话不会被每日入口当作今天的新任务。

## 完成口径

北京时间每日00:00～次日00:00；使用现有shenlun_sessions中已完成、正文非空的正式提交，按material_id去重。同题重复提交只计1道，保存草稿不计完成，模型评分/语义复核失败不影响已经保存的任务完成。目标固定1道，可继续练习；申论进度独立于行测500题目标。接口每日目标与Dashboard使用同一统计入口，并排除无效行测测试作答。

POST /api/shenlun/session新增daily布尔参数，默认false保留旧API恢复行为；前端传true。使用现有表结构和学习核心，没有新增Schema迁移或技能。daily入口在BEGIN IMMEDIATE内恢复/创建，避免并发新建重复会话。
