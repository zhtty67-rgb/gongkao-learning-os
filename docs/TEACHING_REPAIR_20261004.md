# 作答后教学与解析整合修复（2026-10-04）

## 已确认的原因

- 学生中间值未核验，正确的局部乘法掩盖了上游错误；历史教师回复也被继续沿用。
- 模型输出达到预算后直接失败，用户重试仍使用原预算。
- 新教师引导与旧错因诊断、分步精讲、自由追问并存；页面另有教材解析入口。
- 回复使用纯文本或简易加粗处理，没有统一 Markdown 和数学公式渲染。

## 本次处理

- 增加学生推导核验：显式算式检查；对可核验的增长量假设分配，独立计算对应增量和现期差额。只使用题库事实及学生自述，不从历史教师回复取数。
- 原题回放：假设基期 1.4、增长率 8%，增量应为 0.112；对应总额 1.512，与 1.47 的差额为 0.042。0.03 由错误增量产生，不能继续使用。
- 已识别的上游错误先纠正；缺少必要纠正的模型回复不展示为成功教学。追问、旧兼容接口也使用学生值来源约束。
- 输出截断自动完整重生成一次，预算扩大到至少 8192、最多 16384；不修改默认配置，不使用截断片段或内部推理作为答案。
- 作答后统一教师引导、题库解析、完整解析后的追问和新变式练习；题库解析直接读取，无须调用 AI 或教材检索。连续重复查看不堆叠相同解析。
- 删除旧重复教学操作；保留错因记录、补充原因、说明、历次作答、旧对话查看、笔记及回复收藏。不删除旧数据或修改原成绩。
- 统一 Markdown、表格和公式渲染，兼容 `$…$`、`$$…$$`、`\(...\)`、`\[...\]`；代码保持原样，长公式局部滚动，非法公式不使页面崩溃。
