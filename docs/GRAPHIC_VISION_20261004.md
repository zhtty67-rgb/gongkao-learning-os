# 图形教学图片接入验证

原教学请求只有文字，未传原题和选项图片。现在读取受限于本地题库目录的原图，以图片内容块传入现有模型；模型策略必须声明支持图片。文字备用模型不会承接图片请求。图片字节不写入教学记录。

教师引导、旧追问和分步讲解接入同一图片读取函数。失败请求对应的历史用户消息不再进入引导上下文。图形变式使用同知识节点的题库原图，批改切换到变式图片及答案，不改首次成绩。旧的无图片失败提示不再占用页面。

验证：44 项后端测试、2 项浏览器测试通过，生产构建通过。正式 3000 页面显示图片已接入，恢复追问和变式入口；8001 返回 vision_available=true。真实模型在正式数据库副本中完成原题追问、带图变式及变式追问。原有题目、作答、知识节点、17 个技能和历史对话保持不变，数据库完整性及外键检查通过；部署期间新增的用户对话保留。

限制：真实回放中模型仍误数过细线和交点。图片传输接通不等于视觉推理完全可靠；界面已提示对照原图核验，不宣称答案全部正确。标准答案不能用来反编规律，无法核验时要求明确指出待核实。

现有 DeepSeek Flash 图片输入及推理预算参数依据官方文档：https://api-docs.deepseek.com/guides/vision/ 和 https://api-docs.deepseek.com/guides/thinking_mode/ 。图片请求使用 low 推理预算以减少输出截断；一般文字请求保持原设置。
