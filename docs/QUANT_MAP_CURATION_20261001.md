## 导入工具使用

从学习系统根目录运行，双库操作使用 Hub 的 Python 环境，它包含 PostgreSQL/SQLAlchemy 依赖：

```powershell
# 默认仅预览，不写入
..\universal-knowledge-hub\.venv\Scripts\python.exe scripts/import_quant_and_num_reasoning_mindmap.py
# 明确应用；先创建备份，再同步
..\universal-knowledge-hub\.venv\Scripts\python.exe scripts/import_quant_and_num_reasoning_mindmap.py --apply
```

仅预览本地库可使用学习系统环境并明确添加 `--skip-hub`。跳过 Hub 不会被报告为双库成功。Hub 配置从其自身 `.env` 读取，不因调用者工作目录而误用其他配置。

SQLite 在同一事务内写入并核验外键，失败回滚；重复执行保留其他元数据。正式迁移仅包含部分展示字段，旧本机导入还曾添加额外展示列；工具兼容两种布局，摘要始终保存到元数据，不自动修改表结构。此次没有新增迁移。

两种数据库不能共用一个原子事务。工具在写入前核验两端，保存 SQLite 一致性快照和 Hub 框架节点的修改前记录；若 Hub 已提交而本地失败，会留下部分完成记录并以错误结束，不报告全部成功。
