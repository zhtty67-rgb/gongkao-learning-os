# 数量关系教师模型 · 提取规范（Teacher Quant Spec）

你的任务：从协作组公考数量关系 23 讲独立逐字稿与随堂笔记中提取"教师政策（数学方法与速算秒杀规则）"、"课堂真题案例"与"纠偏实录"。

## 炼老师宪法（强制遵守）

1. **只从一手逐字稿与配套官方课件提取**。不得补充个人预设立场。
2. **规则分三级 status**：`explicit` / `inferred` / `hypothesis`，本次提取全部为 explicit。
3. **每条规则必须带 `source[].quote` 课堂原话**，从对应逐字稿中精确复制，终审脚本进行精确子串核查。
4. **单题技巧不得上升为普遍规则**：必须在 `applies_to` 与 `identification_features` 中限定适用范围。
5. **去重与真实性**：4份带(1)的重复文件（第13、14、15、18讲）已严格去重核减，不重复收录；数字推理仅有课件PDF无视频字幕，按缺口记录，严禁捏造虚构逐字稿。
6. **公式与数值计算**：完整保留工程、行程、溶液、排列组合、容斥、最值等计算公式、特值设定规则与检验步骤。

## 核心方法论范畴（category）

- 方程与代数（方程法、不定方程奇偶倍数尾数法）
- 工程问题（给时间型、给效率型、给具体量型）
- 溶液与浓度（十字交叉法、线段比例法、蒸发稀释）
- 基础行程与比例（相遇追及、折返相遇、比例法解行程、流水行船与电梯）
- 经济利润（打折让利、利润率公式、分段计费）
- 排列组合与概率（捆绑法、插空法、隔板法、错位排列、独立重复试验）
- 几何模型（割补平移、周长面积比例放大、表面积与体积切片）
- 容斥与最值（两集合三集合容斥、容斥极值、抽屉原理最不利原则）
- 趣味杂题（周期日期、钟表问题、牛吃草问题、空瓶换酒）
- 考场秒杀与策略（整除特性秒杀、选项代入排除、舍九放弃原则）
