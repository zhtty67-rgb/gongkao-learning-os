# 资料分析教师模型 · 提取规范（Teacher Data Spec）

你的任务：从协作组公考 28 讲资料分析课程逐字稿与配套官方课件中提取"教师政策（计算方法、公式口诀与思维陷阱）"、"课堂真题案例"与"纠偏实录"。

## 炼老师宪法（强制遵守）

1. **只从一手逐字稿与配套官方课件提取**。不得补充个人预设立场。
2. **规则分三级 status**：`explicit` / `inferred` / `hypothesis`，本次提取全部为 explicit。
3. **每条规则必须带 `source[].quote` 课堂原话**，从对应逐字稿中精确复制，终审脚本进行精确子串核查。
4. **多教师来源精确标注**：
   - 主课与刷题答疑（24 讲）：注明教师 `L 老师`；
   - 速算补充（3 讲：DATA06, DATA09, DATA12）：注明教师 `S 老师老师`；
   - 总结加课（1 讲：DATA24）：注明教师 `X 老师老师`；
   - **绝不混称一个真人教师**，在 policy、case、profile 中明确来源。
5. **计算公式与数字精度**：完整保留 415 假设分配法、增长率负向份数法、两期比重差、十字交叉、小分互换、14 大思维陷阱的严密计算步骤与边界约束。

## 核心方法论范畴（category）

- 速算技巧（高位叠加、截位直除、小分互换、415份数法、假设分配法、放缩与拆分）
- ABRX 基础指标（基期量计算、现期量推算、增长量计算、增长率计算、间隔增长率、年均增长率）
- 比重专题（现期比重、基期比重公式、两期比重升降判定、两期比重差值精算）
- 平均数与倍数（现期与基期平均数、平均数增长率公式、多倍与几倍差值）
- 比较类题型（趋势法、双线法、差分法/王者荣耀法、增量大小十字比较）
- 综合分析与思维陷阱（14大思维陷阱、时间与单位坑、正反向设问排查）
- 考场策略与提速心法（35分钟保20分策略、先易后难做题顺序、舍难取易）
