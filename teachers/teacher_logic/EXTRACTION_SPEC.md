# 逻辑判断教师模型 · 提取规范（Teacher Logic Spec）

你的任务：从协作组公考逻辑判断课程逐字稿与官方讲义中提取"教师政策（解题规则与思维模型）"、"课堂真题案例"与"纠偏实录"，构建逻辑判断教师模型知识资产。

## 炼老师宪法（强制遵守）

1. **只从一手逐字稿与配套官方课件提取**。不得补充个人预设立场，老师没讲的方法与口诀不写入规则。
2. **规则分三级 status**：
   - `explicit`：老师在课堂中明确给出的法则、口诀、定理（如"三圈质疑法"、"一二三四五口诀"、"肯前必肯后、否后必否前"、"因果倒置削弱力度最强"）；
   - `inferred`：老师在至少两个独立题目中反复采用的相同思维动作；
   - `hypothesis`：单次出现且未形成明确范式的泛化，不写入。
3. **每条规则必须带 `source[].quote` 课堂原话**，从对应讲次清洗后逐字稿中**逐字精确复制**，终审脚本进行精确子串核查。
4. **单题技巧不得上升为普遍规则**：必须在 `applies_to` 与 `identification_features` 中限定适用范围。
5. **不收集**口头禅、闲聊、招生宣传。
6. **题目案例**：忠实保留题干核心事实、选项、答案与教师推理链。

## 核心方法论范畴（category）

- 归因论证（对比实验、另有他因、否定此因、因果倒置、反因代入、伪他因识别）
- 一般质疑（三圈质疑法、削弱论点、削弱论据、拆桥切断联系、比例类陷阱）
- 一般支持（搭桥建立联系、肯定论据、排除他因、反因代入）
- 前提假设（搭桥法、否定代入法/反向代入验证）
- 翻译推理（充分必要条件、逆否等价、摩根定律、德摩根律、假言连锁）
- 直言命题（所有与某个、三段论格与式、直言对当关系）
- 真假话分析（三类矛盾关系、反对关系、假设法、代入排除法）
- 分析推理（最大信息法、确定信息突破法、列表法、代入法）
- 解释说明（抓反常矛盾现象、两全其美兼顾双方）
- 解题流程（L 老师做题十步法则、审题抓题型定位法）
- 考场策略（蒙猜排除技巧、时间分配、纠结选项取舍原则）
