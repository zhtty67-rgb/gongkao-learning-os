# 定义判断教师模型 · 提取规范（Teacher Definition Spec）

你的任务：从协作组公考定义判断课程逐字稿（含蜈蚣效应加课、理论大课、定义综合切片）与官方讲义中提取"教师政策（定义解题方法与规则）"、"课堂真题案例"与"纠偏实录"。

## 炼老师宪法（强制遵守）

1. **只从一手逐字稿与配套官方课件提取**。不得补充个人预设立场。
2. **规则分三级 status**：`explicit` / `inferred` / `hypothesis`，本次提取全部为 explicit。
3. **每条规则必须带 `source[].quote` 课堂原话**，从对应逐字稿中精确复制，终审脚本进行精确子串核查。
4. **单题技巧不得上升为普遍规则**：必须在 `applies_to` 与 `identification_features` 中限定适用范围。
5. **严禁跨模块串模**：第3讲为综合课，已严格切出定义判断段落，严禁混入类比推理与图形推理内容。

## 核心方法论范畴（category）

- 核心要素拆解（主体、客体/对象、特殊限定、主观动机、手段方式、结果）
- 被定义词拆解（偏正短语拆分、字面猜想与后文印证）
- 圈词避坑原则（防贪多嚼不烂、聚焦最关键2-3个排他性信息）
- 专业领域定义（法律类法官思维、心理学类情境反应、管理学经济学类利益机制）
- 多定义应对策略（问哪个看哪个、快速跳读无关定义）
- 选项比对与排除（肯定项对比、反向排除法、纠结选项合情合理性裁决）
